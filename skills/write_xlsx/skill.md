# write_xlsx skill
# ---------------------------------------------------------------------------
# 摘要
# 从零创建 Excel (.xlsx) 文件，支持多工作表、表头格式化、数据写入。
#
## 使用场景
# - 创建新的 Excel 报表
# - 导出数据为 Excel
# - 生成多工作表工作簿
#
# 包含 1 种工具:
#   write_xlsx - 创建 .xlsx 文件
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── write_xlsx ──
# 从零创建 Excel 文件。
#
# 参数:
#   file_path (string, 必填) 输出文件路径
#   sheets (array, 必填) 工作表列表, 每项:
#     {
#       "name": "工作表名",
#       "headers": ["列1", "列2", ...],     // 可选, 会自动格式化
#       "data": [["a","b"], ["c","d"], ...], // 可选, 二维数组
#       "merge_cells": ["A1:C1", ...]        // 可选, 合并区域
#     }
#
# 自动特性:
#   - 表头自动格式化为蓝底白字加粗居中
#   - 列宽自动适配内容（含中文字符宽度）
#   - 目录自动创建
# ---------------------------------------------------------------------------

# search_docx skill
# ---------------------------------------------------------------------------
# 摘要
# 在 Word 文档中搜索关键词，返回匹配的段落和表格位置。
#
# ⚠️ 与 search_document 的区别:
#   search_docx     → 仅 DOCX，返回段落/表格等详细结构化位置
#   search_document → 所有格式（DOCX/PDF/XLSX/PPTX/TXT 等），目录递归，近义词扩展
#
## 使用场景
# - 在 Word 文档中查找特定内容
# - 需要精确定位到段落或表格单元格
#
# 包含 1 种工具:
#   search_docx - 在 DOCX 中搜索关键词
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── search_docx ──
# 在 Word 文档中搜索关键词。
#
# 参数:
#   file_path (string, 必填) DOCX 文件路径
#   keyword (string, 必填) 搜索关键词
#
# 输出: 匹配的段落和表格位置列表。
# ---------------------------------------------------------------------------

# 用户偏好设置

> 此文件存储用户的个性化偏好数据，用于优化打车体验。当用户的 query 中没有明确指定时，系统会根据此文件的偏好自动匹配。

## 优先级说明

1. **用户 query 参数**（优先级最高）：用户在当前对话中明确指定的地址、车型等
2. **PREFERENCE.md 偏好数据**（优先级次之）：用户预设的个性化偏好

## 地址别名

| 别名 | 地址名称 | 经度 | 纬度 | 城市 |
| ---- | -------- | ---- | ---- | ---- |
| 家   |          |      |      |      |
| 公司 |          |      |      |      |

> 说明：
> - "家"和"公司"为内置别名，支持"从家到公司"、"打车回家"等简化表达。
> - 精确优先，语义兜底：精确匹配别名（"家"只匹配"家"，不会匹配"妈妈家"）。

| 配置项     | 值   | 说明 |
| ---------- | ---- | ---- |
| 默认车型   |      | 无明确需求时使用 |

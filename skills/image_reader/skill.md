# image_reader skill
# ---------------------------------------------------------------------------
# 摘要
# 读取本地图片文件，转换为 base64 编码供 LLM 视觉能力识别。
# 支持 JPG/PNG/GIF/BMP/WebP 等多种格式，自动调整尺寸控制 token 消耗。
#
## 使用场景
# - LLM 需要分析/描述图片内容时
# - 需要提取图片中的文字信息
# - 批量为文档或 PPT 准备图片素材
# - 预处理大尺寸图片以控制 token 消耗
#
# 包含 1 种子操作:
#   read_image - 读取图片并转换为 base64
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── read_image ──
# 读取本地图片文件，转换为 base64 编码供 LLM 视觉识别。
#
# 参数:
#   file_path (string, 必填) 图片文件路径，支持相对和绝对路径。
#         示例: "screenshot.png"
#   max_size (integer, 可选, 默认 1024) 最大尺寸（宽或高像素），超出按比例缩放。
#         示例: 512  (小图，快速)
#         示例: 1536 (大图，保留细节)
#   include_info (boolean, 可选, 默认 true) 是否返回图片元信息。
#
# 输出: base64 编码字符串及图片元信息，可直接用于 LLM 视觉消息。
# ---------------------------------------------------------------------------

# 注意事项
# 1. 需要安装 Pillow 库: pip install Pillow
# 2. RGBA/P 模式图片自动转为 RGB，避免兼容问题
# 3. base64 数据存储在 ToolResult.details 中，不在 content 正文内
# 4. 建议 max_size <= 2048，过大会显著增加 token 消耗

# get_current_time skill
# ---------------------------------------------------------------------------
# 摘要
# 获取当前准确时间。LLM 的训练截止时间远早于实际当前时间，
# 因此每次进行需要时间上下文的任务前都应调用此工具。
#
# ⚠️ 重要提示
# LLM 必须在使用任何与时间相关的参数前调用此技能，避免使用错误的年份或日期。
#
## 使用场景
# - 用户问"现在几点"、"今天日期"
# - 需要当前时间戳
# - 需要特定时区时间
# - 文件命名需要日期
# - 任何需要时间上下文的任务
#
# 包含 1 种工具:
#   get_current_time - 获取当前时间
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── get_current_time ──
# 获取当前时间，支持多种格式和时区。
#
# 参数:
#   format (string, 可选) Python strftime 格式, 默认 "%Y-%m-%d %H:%M:%S"
#       常用: "%Y-%m-%d" (仅日期), "%H:%M:%S" (仅时间)
#   timezone (string, 可选) local / utc / IANA 时区名 (如 "Asia/Shanghai"), 默认 local
#   return_timestamp (boolean, 可选) 是否返回 Unix 时间戳, 默认 false
#
# 输出:
#   content: 格式化时间字符串
#   extras: timezone + iso + timestamp(可选)
#
# strftime 常用格式:
#   %Y - 四位年份  %m - 月份  %d - 日期
#   %H - 小时(24h)  %M - 分钟  %S - 秒
# ---------------------------------------------------------------------------

# image_generate skill
# ---------------------------------------------------------------------------
# 摘要
# AI 图片生成技能。调用火山引擎 ARK（豆包 Seedream）图像生成服务，根据文本提示词生成图片并保存到本地。
# 基于 OpenAI 兼容接口，支持多种模型和尺寸。
#
## 使用场景
# - 用户说"帮我画一张..."、"生成一张...图片"
# - 为 PPT、文档、网页创作配图
# - 根据描述生成概念图、插画、背景图
#
# 包含 1 种子操作:
#   generate_image - 根据提示词生成图片并保存
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── generate_image ──
# 调用 AI 图像生成服务生成图片并保存到本地。
#
# 参数:
#   prompt (string, 必填) 图片生成提示词，描述想要的画面内容。
#         示例: "一只可爱的橘猫在窗台上晒太阳，温馨治愈风格"
#   save_dir (string, 必填) 图片保存目录。LLM 应根据项目目标文件夹自行决定。
#         示例: "output/images"
#   size (string, 可选, 默认 "2K") 输出尺寸。
#         示例: "2K", "1024x1024"
#   model (string, 可选) 模型名称。不填则使用 Settings 中配置的模型
#         （Settings → Skill Keys → ImageGen → Model），未配置时回退到 doubao-seedream-4-5-251128。
#
# 输出: 生成图片的文件路径、尺寸、格式信息。
#
# API key 配置:
#   需要火山引擎 ARK API Key。在 Settings → Skill Keys → ImageGen 中配置。
#   模型名也在该处配置，必须填写用户账户中实际可用的模型，否则会调用失败。
#   注册地址: https://console.volcengine.com/ark/
# ---------------------------------------------------------------------------

# 注意事项
# 1. 需要安装 openai 库: pip install openai
# 2. 图片生成需要消耗 API 额度
# 3. 生成时间通常在 5-30 秒
# 4. save_dir 必须由 LLM 根据项目目标文件夹自行决定，不要写死

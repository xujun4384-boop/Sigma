# map_video - 高德真实地图引擎（导演组内部）

> 把**真实地图镜头**做成一段 mp4：真实中国/世界行政区、真实驾车/步行/骑行路线、地点标注、行程演示。
> 底层是高德 JS API 2.0 + `AMap.DistrictLayer`，Playwright 逐帧截图 → ffmpeg。

## 和 styled 的 `visualStyle="map"` 的区别

| | `styled` + `visualStyle: "map"` | `amap` 引擎（map_video） |
|---|---|---|
| 地图 | **风格化纸地图**：米色纸/等高线/图钉/虚线 | **真实地图**：真实省界/国界/道路/路线 |
| 地理 | 不保证真实；适合虚构、隐喻、绘本叙事 | 真实经纬度、真实地点、真实路线 |
| 用途 | 故事里的“地图意象”、迁徙隐喻、纸图质感 | 行程、路线、地点、中国/世界版图、数据地图 |
| 人物 | 图钉/圆点/小人符号 | 不画人物，只有真实地图和标记 |

**选型**：用户说的是真实地点/行程/路线/中国地图/世界地图 → `amap`；
只是在画面里要一个“像地图的图形/纸图” → `styled` 的 `map` 风格。

## spec

由导演组把 spec 写在面板的 `map` 字段，本工具只渲染。

```json
{
  "kind": "route | region | world | flight",
  "title": "标题",
  "subtitle": "副标题",
  "kicker": "顶部小标签",
  "theme": "dark | light",
  "city": "北京",
  "list": true,
  "markers": [
    {"name": "北京", "sub": "BEIJING", "coord": [116.4074, 39.9042], "side": "left-up"}
  ],
  "route": {
    "origin": "三里屯",
    "destination": "国贸",
    "mode": "driving | walking | riding",
    "origin_name": "起点显示名",
    "destination_name": "终点显示名"
  },
  "flight": {
    "from": "上海",
    "to": "大连",
    "arc": 0.16
  },
  "region": {
    "soc": "CHN",
    "name": "北京市",
    "adcode": "110000",
    "depth": 1,
    "bounds": [[73.502355, 3.83703], [135.09567, 53.563624]],
    "highlight": ["北京市", "上海市", "天津市", "重庆市"]
  },
  "world": {
    "highlight": ["CHN", "USA", "JPN"],
    "center": [0, 20]
  }
}
```

### route（行程/路线）
- `origin` / `destination` 可以是**中文地名**或 `[经度, 纬度]`；地名由引擎地理编码。
- **强烈建议写 `city`**（如 `"北京"`）：同名地点很多（三里屯/国贸在多地都有），不写城市会解析到错误地点。
- `mode`：`driving`（默认）/ `walking` / `riding`。
- 自动计算距离/时间；`subtitle` 留空时会自动填 `x.x km · y min`。
- 画面：真实路线逐段生长、镜头跟随、起点/终点标记；路线过长时自动按 bbox 调整缩放。

### flight（飞机航线示意）
- `from` / `to`：城市名或 `[经度,纬度]`；`arc` 可选（默认 0.16，弧线弯曲程度）。
- 画面：真实城市位置 + 弧线航线 + 飞机图标沿弧线飞 + 已飞轨迹 + 直线距离。
- 这是**航线示意**，不是真实航班轨迹；副标题会自动带“航线示意”，不要伪造成真实航班数据。
- 相机固定在能看到整条航线的尺度，飞机和轨迹提供运动；适合飞机/跨城/旅行段。

### region（中国/省市行政区）
- 默认 `soc: "CHN"`，`depth: 1` 显示省级。
- `highlight` 写行政区名称或 adcode，填高亮色。
- `markers` 写城市点；没有坐标时用 `name` 地理编码。
- 中国默认使用完整版图 bbox（含南海诸岛）；单省可传 `bounds` 或 `name`（如“北京市”）+ `adcode`。
- 单省/单市用 `name` 或 `adcode` 定位到**省级视图**（zoom ~7.9，Country 图层上高亮该省）；
  城市街道级/具体行程请用 `route`。
- 画面：只显示中国行政区面，不显示底图/周边国家（`features: []` + 深色底）。

### world（世界）
- `highlight` 写国家 `SOC`（如 `CHN`、`USA`、`JPN`）或中文国名。
- 画面：世界行政区面 + 高亮国家 + 标记。
- 默认以 0° 经线居中、zoom 3（适合 1920×1080；避免世界横向重复）。
  境外城市标记最好直接写 `coord`，中文地名在境外的地理编码不稳定。
- 当前针对 16:9 横版优化；4K/竖屏需要另调 zoom/center。

## Key 配置

在应用里打开 **设置 → 技能 API 配置 → 高德地图**，填写：

- **高德 Web端(JS API) Key**
- **安全密钥 jscode**

应用会把这两项注入 `SkillManager`，再由它传给 `map_video`；**不要写进程序目录**，也不要提交到 git。
命令行调试时才用环境变量 `AMAP_JS_KEY` / `AMAP_SECURITY_CODE`。

如果 Key 配置了域名白名单，请允许 `127.0.0.1`（本引擎本地渲染）或清空白名单；
否则会报 `INVALID_USER_DOMAIN` / 地图不加载。

## 合规

- 高德 logo 和审图号不能遮挡；本引擎会在左下角保留它们（暗色底图加浅色底保证可读）。
- 暗色样式下高德的审图号只在样式切换时回填，引擎会自动「先 normal 再切 dark」。
- 地图内容不得用于违法违规用途；商用请按高德开放平台协议确认授权与配额。

## 边界

- 只渲染地图画面，不生成旁白/字幕/BGM/音效；这些仍由导演组其他部门负责。
- 地图需要联网加载 JS API/瓦片/地理编码；离线环境不可用。
- 境外只有国界/洲名级别，没有境外街道细节；境外城市街区请换 Mapbox/MapLibre。
- 渲染失败（Key/网络/地名解析）会返回明确错误，由导演组决定降级（默认降级 opendesign）。

# sub_agent skill
# ---------------------------------------------------------------------------
# 摘要
# 并行子 Agent 创建与编排。主 Agent 可创建多个独立子 Agent，分配给它们不同的任务，
# 所有子 Agent 通过 ThreadPoolExecutor 并行执行，完成后汇总结果。
# 每个子 Agent 拥有独立的上下文窗口和工具访问权限。
#
## 使用场景
# - 多模块并行开发（前端+后端同时进行）
# - 批量文件处理（多个独立文档同时处理）
# - 并行代码审查
# - 分离的调研和实现任务
#
# 包含 1 种子操作:
#   sub_agent - 创建并行子 Agent 执行任务
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── sub_agent ──
# 创建多个并行子 Agent 执行独立任务。
#
# 参数:
#   tasks (array, 必填) 子 Agent 任务列表。每项为对象:
#     {
#       "type": "plan" | "coder" | "explore",  # 子 Agent 类型
#       "prompt": "...",                         # 详细任务描述
#       "description": "...",                    # 简短标签（日志/UI 显示）
#       "cwd": "...",                            # 可选，工作目录
#       "allowed_tools": [...]                   # 可选，工具白名单
#     }
#
# 子 Agent 类型:
#   plan    - 设计师/规划者，只读工具集
#   coder   - 实现者，完整工具集（含 write/bash/sandbox_run）
#   explore - 探索者，只读工具集
#
# 并行机制:
#   - ThreadPoolExecutor，最多 6 并发
#   - 每个子 Agent 独立 LLM 客户端 + 独立上下文
#   - 最大 8 轮工具调用
#   - 实时进度推送（SSE → 前端 SubAgent UI）
#   - 结果按任务顺序返回
#
# 前端 UI:
#   前端会为每个 sub_agent 调用显示一个可折叠的任务面板，
#   实时展示每个子 Agent 的状态（运行中🔄/完成✅/失败❌）和轮次。
# ---------------------------------------------------------------------------

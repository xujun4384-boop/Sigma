# writing_polish skill
# ---------------------------------------------------------------------------
# 摘要
# 去 AI 味润色。让文字听起来像真人写的而非 AI 生成。
# 去除机器腔、注入人味、让文字有脉搏。直接在对话中应用规则改写。
#
## 使用场景
# - 用户觉得回复"太AI了"
# - 改写报告/文章使其更像人写的
# - 降 AI 检测率
#
# 包含 1 种工具:
#   writing_polish - 获取去 AI 味润色规则指南
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── writing_polish ──
# 去 AI 味润色指南。可选直接传入文本。
#
# 参数:
#   text (string, 可选) 待润色的文本
#
# 规则分层:
#   致命级 - 知识截止用语/聊天机器人腔/不存在的引用
#   高信号 - AI词库替换(助力/赋能/彰显等)
#   中信号 - 假引用/流水连接词/废话开篇
#   风格级 - 句型限制/段落节奏/具体性
#
# 改写原则: 有态度、允许粗糙、具体而非概括、节奏变化、承认复杂性、允许"我"
# ---------------------------------------------------------------------------

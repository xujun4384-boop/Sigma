# deep_research skill
# ---------------------------------------------------------------------------
# 摘要
# 多维度并行深度调研。拆解主题为若干研究维度（≥6个），每个维度派一个子Agent并行搜索
# （每个≥10次独立搜索），交叉验证后提取洞察，生成结构化研究报告。
#
## ⚠️ 与 web_search 的关键区别:
#   web_search  → 单次搜索，返回 5-10 条摘要，适合快速查一个事实/数据
#   deep_research → 6+维度 × 10+次搜索 = 60+次搜索，并行执行，交叉验证，
#                   最终产出结构化报告 (research/report.md)
#   用 web_search 查"今天天气"、"Python 3.13 新特性"就够了
#   用 deep_research 做"行业竞争格局分析"、"技术趋势调研报告"
#
## 使用场景
# - 行业分析、竞争格局、技术趋势调研
# - 写研究报告、调研报告
# - 需要从多角度系统性研究一个问题
# - 单次 web_search 结果被截断或信息不够全面时
#
# 包含 1 种工具:
#   deep_research - 获取深度调研五步流水线指南
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── deep_research ──
# 多维度并行深度调研工作流指南。
#
# 参数:
#   topic (string, 必填) 调研主题
#
# 五步流水线:
#   1. 维度拆解 → ≥6个研究维度, 每维度有明确搜索方向
#   2. 并行搜索 → sub_agent 派子Agent, 每维度≥10次 web_search, 结果存 research/dim*.md
#   3. 交叉验证 → 高/中/低/冲突 四类归档, 存 research/cross_verification.md
#   4. 洞察提取 → ≥5个跨维度洞察, 存 research/insights.md
#   5. 生成报告 → 结构化报告, 存 research/report.md
#
# 原则:
#   - 不搜索不发言, 每条声明必须有来源引用
#   - 矛盾不掩盖, 两方数据都记录
#   - 优先权威来源: 政府 > 学术 > 主流财经 > 行业报告 > 企业公告
# ---------------------------------------------------------------------------

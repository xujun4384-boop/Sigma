# footage_video - 用户自备素材引擎（内部）

> 导演组内部引擎：把**用户自己提供、放在项目文件夹里的视频**直接用成一段画面。
> 不是 AI 生成、不耗视频额度；只做规格统一，不改内容。

## 何时使用

- 用户明确说「我自己提供了一段 mp4 / 素材放在项目文件夹 / 用我这段视频开场或做某一段」。
- 素材路径由用户给出或能在项目目录里对应上；**导演不得自行臆造素材，也不要在用户没提时主动选用本引擎**。

## 行为契约

- 输入不限容器（mp4 / mov / mkv / webm / avi …），**输出统一为 mp4**（H.264 + yuv420p）：
  非 mp4 素材自动转换，输出路径若不以 `.mp4` 结尾会自动改名。
- 段长 = 素材原长；`clip_seconds` > 0 时只取前 N 秒。不补帧、不拉伸、不改节奏。
- 画布适配：`fit=contain`（默认，等比缩放 + 补黑边，完整保留画面）/ `cover`（等比放大 + 居中裁切铺满）。
- 统一到项目画布（**默认 1920×1080**）、帧率、像素格式与 SAR，保证能与其它引擎的段直接拼接。
- 原声默认保留：从素材抽出独立音频轨（`*_src.wav`）返回给导演。
  合成部门会丢弃视频内嵌音轨，所以原声必须走独立音频轨；**该段若有人声旁白，旁白优先**。
- 不叠加标题/蒙版：标题包装由导演用 `title_overlay` 在底片上叠加。

## 参数

- `input_path`（string，必填）素材路径（相对项目目录或绝对路径；mp4/mov/mkv/webm 等均可）。
- `output_path`（string，必填）输出 mp4 路径（非 `.mp4` 后缀会自动改为 `.mp4`）。
- `width` / `height` / `fps`（integer，可选）目标画布，默认 1920×1080@30。
- `fit`（string，可选）`contain`（默认）/ `cover`。
- `clip_seconds`（number，可选）只取前 N 秒，默认 0=整段。
- `keep_audio`（boolean，可选）保留素材原声，默认 true。

## 输出

```
{
  "output_path": "...mp4",       // 非 .mp4 目标会自动改成 .mp4
  "duration": 10.0,
  "source_duration": 10.0,
  "audio_path": "..._src.wav",   // 素材无音轨或 keep_audio=false 时为空
  "has_source_audio": true,
  "fit": "contain",
  "clipped": false,
  "converted_to_mp4": false      // 输入不是 mp4 时为 true（已转码）
}
```

## 边界

- 素材不存在 / 不是视频 / 无视频流 → 直接失败并说明，**不降级成其它画面**（用户指定了素材，不能用别的东西冒充）。
- 不做转场、字幕、配乐、音效：这些仍由合成组与各专业组负责。

# web_search skill
# ---------------------------------------------------------------------------
# 摘要
# 联网搜索技能。使用 Kimi Search V2 搜索互联网信息，获取最新搜索结果摘要和链接。
# 适合快速查一个事实或数据。如需多维度系统性能调研（行业分析/竞争格局等），请用 deep_research。
#
## ⚠️ 与 deep_research 的区别:
#   web_search  → 单次搜索，5-10 条摘要，轻量快速
#   deep_research → 6+维度 × 10+搜索, 交叉验证, 生成结构化报告
#
## 使用场景
# - 需要查询当前最新的新闻、事件、数据
# - 需要验证某个事实或寻找权威来源
# - 需要查找技术文档、论文、博客、公开页面
# - 需要为写作、报告等内容收集素材
#
# 包含 1 种子操作:
#   web_search - 使用 Kimi Search V2 搜索互联网信息
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── web_search ──
# 使用 Kimi Search V2 搜索互联网信息。
#
# 参数:
#   query (string, 必填) 搜索关键词。
#         示例: "Python 3.13 新特性"
#   limit (integer, 可选, 默认 5) 返回结果数量，最大 10。
#         示例: 10
#
# 输出: 格式化的搜索结果列表，包含序号、标题、URL、摘要。
#
# API key 配置:
#   需要 Kimi API key。通过后端 config.json 的 kimi_api_key 或环境变量 KIMI_API_KEY 配置。

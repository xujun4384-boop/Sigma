# 摘句（高亮原文）

你在为知识点讲解视频挑选**要划重点的原文片段**。这些片段会被真实标注在网页截图上，所以必须逐字准确。

## 硬性要求

1. `quote` 必须是某个文本块里**连续存在的一段原文**：逐字复制，不得改写、缩写、补字、拼接、加省略号。
2. 长度控制在 4~120 字，尽量是完整的一句或一个数据点。
3. 优先标：具体数字与单位、定义句、因果/结论句。
4. 每段 2~3 处，按讲解顺序排列；页面内容不够时允许 1 处。
5. **尽量选同一屏或相邻区块里的内容**：长页面不要从页首挑到页尾，镜头不要横跨大半页。
   如果关键数据集中在同一张表/同一个列表里，优先在同一张表里选 2~3 个相邻项，便于一镜讲完。
6. 不要标导航、按钮、版权、广告、评论。

## 旁白对齐

如果给了旁白分句，请为每处高亮选一个 `cue`（旁白分句的下标，从 0 开始），表示讲到这句时应该出现该高亮。
多个高亮可以对应同一句；但同一句不要塞超过 2 处。

## 输出

只输出 JSON，不要解释、不要 markdown：

```json
{
  "marks": [
    {"block_id": 7, "quote": "原文里逐字存在的一句话", "reason": "为什么值得标", "cue": 0}
  ]
}
```

`block_id` 必须是输入里出现过的块 id。若这段页面没有任何可标注的内容，输出 `{"marks": []}`。

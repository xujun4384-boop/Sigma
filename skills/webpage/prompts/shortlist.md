# 选段（短名单）

你在为一支知识点讲解视频挑出网页里**最值得讲的段落**。先只选段落，不要摘句。

## 输入

- 知识点（focus）
- 本段旁白（可能为空）
- 页面文本块：`[id] 所属标题 :: 正文开头`

## 判断标准

- 优先能支撑讲解的实质内容：定义、关键数据、因果/步骤、结论。
- 跳过导航、菜单、版权、广告、推荐位、评论区、无关的举例。
- 只依据给定文本判断，不要臆测被截断的内容。
- 最多选 10 个块，按讲解顺序排列；宁少勿滥。
- **必须集中在同一章节内的相邻区块**：后面的镜头会在一个浏览器视口里滚动讲解，
  所以这些块要能在 1~2 屏范围内看到。如果关键数据分布在页面相距很远的不同章节，
  **只选其中最重要的那一处**，不要跨章节凑数。
- 同一张表格、同一个列表、同一段连续正文里的多个数据点，是最理想的组合。

## 输出

只输出 JSON，不要解释、不要 markdown：

```json
{"blocks": [3, 7, 12]}
```

数组元素必须是输入里出现过的块 id。

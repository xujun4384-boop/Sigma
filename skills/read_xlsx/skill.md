# read_xlsx skill
# ---------------------------------------------------------------------------
# 摘要
# 读取和解析 Microsoft Excel (.xlsx) 文件的内容，提取工作表数据。
#
## 使用场景
# - 查看 Excel 文件内容时
# - 分析表格数据
# - 提取工作表信息
#
# 包含 1 种工具:
#   read_xlsx - 读取 .xlsx 文件内容
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── read_xlsx ──
# 读取 Excel 文件，列出工作表并返回数据。
#
# 参数:
#   file_path (string, 必填) Excel 文件路径
#   sheet_name (string, 可选) 指定工作表名称, 不填读取全部
#   data_only (boolean, 可选) 是否只读取公式计算后的值（默认 True）
#
# 输出: 包含 sheets 字典, 每项有 row_count/column_count/data
# ---------------------------------------------------------------------------

# custom_agent skill
# ---------------------------------------------------------------------------
# 摘要
# 调用用户自定义的专用 Agent。每个 Agent 拥有独特的系统提示词、工具集和模型配置，
# 适用于需要特定专业知识或固定工作流的任务。
#
# 使用场景
# - 需要特定搜索策略的信息检索
# - 特定编程范式或框架的代码生成
# - 专业领域的文档分析或数据处理
# - 任何需要独立人设和工具集的任务
#
# 包含 1 种工具:
#   custom_agent - 调用用户自定义 Agent
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── custom_agent ──
# 调用用户自定义的专用 Agent 执行任务。
# Agent 使用预设的 system_prompt、工具集和模型独立运行。
#
# 参数:
#   agent_name (string, 必填) 要调用的自定义 Agent 名称
#   prompt (string, 必填) 发送给 Agent 的详细任务描述
#
# 上下文:
#   隔离模式 - Agent 只有自己的 system_prompt 和任务描述，
#   不共享主对话历史（与 sub_agent 行为一致）
# ---------------------------------------------------------------------------

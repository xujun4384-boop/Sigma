# image_search skill
# ---------------------------------------------------------------------------
# 摘要
# 通过 Tavily API 在网络上搜索图片，返回图片 URL 列表及相关来源信息。
# 适用于为文档、PPT 演示文稿搜索配图，或查找特定主题的图片素材。
#
## 使用场景
# - 为 PPT 演示文稿搜索配图
# - 为 Word 文档查找相关插图素材
# - 需要特定主题的图片 URL 列表
#
# 包含 1 种子操作:
#   search_image - 搜索网络图片并返回 URL 列表
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── search_image ──
# 通过 Tavily API 搜索网络图片，返回图片 URL 及来源信息。
#
# 参数:
#   query (string, 必填) 图片搜索关键词。
#         示例: "人工智能 科技 未来"
#   max_results (integer, 可选, 默认 5) 返回结果数量，范围 1-10。
#         示例: 3
#
# 输出: 搜索结果列表，每项包含图片 URL、标题、来源 URL。
#
# API key 配置:
#   需要 Tavily API Key。通过后端传入 tavily_api_key 配置。
#   注册地址: https://tavily.com
# ---------------------------------------------------------------------------

# 注意事项
# 1. Tavily API 免费额度有限（每月 1000 次），注意使用频率
# 2. 返回的是图片 URL，不自动下载图片文件
# 3. 搜索结果中的图片可能有版权限制，请注意使用场景
# 4. 图片 URL 可能过期或无法访问，建议及时使用

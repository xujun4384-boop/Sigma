# file_operations skill
# ---------------------------------------------------------------------------
# 摘要
# 文件系统操作技能。提供文件和命令操作能力：读取文件内容、创建/写入文件、
# 执行 Shell 命令。这是 Sigma 与文件系统交互的入口，涵盖本地文件和 Shell 操作需求。
#
## 使用场景
# - 需要查看项目中的源代码文件以理解逻辑
# - 需要创建新文件或修改已有文件的内容
# - 需要在终端执行构建、测试、安装依赖等命令
# - 需要浏览目录结构了解项目组织
#
# 包含 3 种子操作:
#   read  - 读取文件内容（带行号）
#   write - 创建/覆盖文件
#   edit  - 精确搜索替换文件内容
#   bash  - 执行 Shell 命令
# ---------------------------------------------------------------------------

# ═══ 参数详情 ═══

# ── read ──
# 读取文件内容。推荐不传 offset/limit 以一次性读取整个文件，返回带行号前缀的文本。
# 仅在文件超过 2000 行被自动截断（返回 [TRUNCATED] 标记）后，才用 offset/limit 继续读取剩余部分。
# 禁止在没有看到 [TRUNCATED] 信号的情况下主动分段读取。
#
# 参数:
#   file_path (string, 必填) 文件路径。支持相对路径和绝对路径。
#             示例: "src/main.py", "/etc/config.json"
#   offset    (integer, 可选) 起始行号。仅在 [TRUNCATED] 后继续读取时使用，不要主动设置。
#             示例: 2001 从第 2001 行继续
#   limit     (integer, 可选) 最大读取行数。仅在 [TRUNCATED] 后使用，不要预先设置。
#             示例: 500 再读 500 行
#
# 输出: 带行号的文件内容，格式如 "     1|import os"
#
#
# ── write ──
# 创建新文件或覆盖已有文件。自动创建不存在的父目录。
#
# 参数:
#   file_path (string, 必填) 文件路径。
#             示例: "src/utils/helpers.py"
#   content   (string, 必填) 要写入的完整文件内容。
#             可以是代码、JSON、Markdown 等任意文本
#
# 输出: "文件已写入: xxx (N 字节)"
#
#
# ── edit ──
# 精确搜索替换文件内容（替换首次匹配）。用于修改代码文件中的特定段落。
# old_str 必须精确匹配（含所有空格、缩进、空行），new_str 为替换后的内容。
# 如果 old_str 在文件中不唯一（出现多于一处处），工具会报错并要求增加上下文使其唯一。
#
# 参数:
#   file_path (string, 必填) 文件路径。
#             示例: "src/utils/helpers.py"
#   old_str   (string, 必填) 要替换的原文本。必须精确匹配文件中实际存在的字符串（含所有空格缩进）。
#             示例: "def foo():" 或一整段代码
#   new_str   (string, 必填) 替换后的新文本。
#             示例: "def bar():" 或修改后的整段代码
#
# 输出: "已编辑: xxx 第 N 行 (替换 1 处)"
# 提示: 如果匹配不唯一，工具会返回文件中实际出现的次数和首处上下文，你需要包含更多上下文使其唯一
#
#
# ── bash ──
# 在工作目录中执行 Shell 命令并返回输出。支持超时控制。
# 适用于运行构建脚本、安装依赖、执行测试、Git 操作等。
#
# 参数:
#   command (string, 必填) 要执行的 Shell 命令。
#           支持管道、重定向等 Shell 语法
#   timeout (integer, 可选, 默认 120) 超时时间（秒）。
#           超时后进程被终止
#
# 输出: 命令的 stdout+stderr 合并。超过 4000 字符截断。
